# 👟 Adidas E-Commerce Storefront Clone

> A responsive, high-performance e-commerce frontend architecture built entirely from scratch to simulate the Adidas shopping experience.

**Status:** 🚧 Work In Progress (WIP) - Currently developing the `Shop` pages and refining core classes.

## 🎯 Project Overview

This project is not just a UI clone; it's a deep dive into building a scalable frontend architecture without relying on modern frameworks like React or Vue. The primary goal is to demonstrate a strong command of **Vanilla JavaScript fundamentals**, memory management, and clean code principles.

## 🏗️ Architecture & Technical Approach

The entire application logic is driven by **Object-Oriented Programming (OOP)**. Instead of procedural spaghetti code, the project is divided into logical entities:

- **Custom State Management:** Handling UI updates dynamically.
- **Modular Classes:** Separating concerns (e.g., `Product`, `Cart`, `UIHandler`).
- **Vanilla DOM Manipulation:** Efficient rendering and event delegation for optimal performance.

## 💻 Tech Stack

- **HTML5 & CSS3** (Semantic markup & fully responsive design)
- **Pure Vanilla JavaScript** (ES6+ Features, Classes, Modules)
- **Tooling:** ESLint (for strict code quality), Node.js environment setup.

## 🚀 Why Vanilla JS?

While modern frameworks are the industry standard, this project was intentionally built with Vanilla JS to solidify the core fundamentals of web engineering, proving an ability to understand _how_ things work under the hood before abstracting them.
